## Features

- **Hidden from screen capture:** one-click Privacy mode hides the window from screenshots, screen recordings and screen sharing.
- **Live voice-to-text:** records your system audio and turns it into text on your own PC, with live updates while the speech is playing.
- **Auto-send to ChatGPT:** text appears in your open ChatGPT tab and is sent automatically after a short pause.
- **Stay logged in:** log in to ChatGPT once, no need to log in again after closing the app.
- **Instant show hotkey:** press **Ctrl+Shift+D** from any app to bring the window to the front. It stays out of the taskbar.
- **Built-in browser with tabs:** open, close and switch tabs, with keyboard shortcuts (Ctrl+T, Ctrl+W, Ctrl+L).
- **Extension support:** add your own browser extensions from the extensions folder.
- **Offline speech recognition:** the speech model is included in the installer, so no internet is needed for transcription.
- **Easy install:** a single Windows installer, nothing else to install (no Python, no setup).
- **Device licensed:** each copy is made for one device.
